# Product Requirements Document (PRD)

## Problem
Property owners lack a unified platform to list their properties for rent with flexible rental durations (shortlet, weekly, monthly, annual), making it difficult to reach a wide range of potential tenants.

## Goals
- Allow property owners to list properties for rent.
- Support multiple rental durations: shortlet, weekly, monthly, annual.
- Make listings discoverable by tenants searching for different rental terms.

## User Stories
- As a property owner, I want to list my property for rent and choose the rental duration (shortlet, weekly, monthly, annual) so I can reach more tenants.
- As a tenant, I want to search for properties available for my preferred rental duration.

## Acceptance Criteria
- Owners can create a property listing and select one or more rental durations.
- Listings display the available rental durations.
- Tenants can filter/search by rental duration.

## Future Backlog
- Payment integration for rental transactions.
- Calendar availability for shortlet bookings.
- Reviews and ratings for properties and owners.
- Automated reminders for renewals and payments.

## TL;DR
Enable property owners to list properties for rent with flexible durations (shortlet, weekly, monthly, annual) and allow tenants to search/filter by these options.
