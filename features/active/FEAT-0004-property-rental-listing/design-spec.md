# UI/UX Design Spec

## UX Flows
- Owner flow: List property → Select rental durations (shortlet, weekly, monthly, annual) → Submit listing
- Tenant flow: Search properties → Filter by rental duration → View results

## Component Inventory
- Property Listing Form (with rental duration selector)
- Property Card (shows available durations)
- Search Filter (by rental duration)

## Style Decisions
- Use clear icons/labels for each rental duration
- Highlight available durations on property cards

## Accessibility
- All controls labeled for screen readers
- Duration selection accessible via keyboard

## TL;DR
Simple, accessible UI for listing and searching properties by rental duration.
